The six functions below come from Anton Korinek, "Generative AI for Economic Research: Use Cases and Implications for Economists," Journal of Economic Literature (2023). He sorts the research uses of generative AI into six functions, each with its own set of tasks. Each function has its own page on this site.

1. [Ideation and feedback]({{ "/tool/ideation/" | relative_url }}): brainstorming, evaluating ideas, and providing counterarguments.
2. [Writing]({{ "/tool/writing/" | relative_url }}): synthesizing text, editing text, evaluating text, and generating titles and headlines.
3. [Background research]({{ "/tool/background/" | relative_url }}): summarizing text, searching the literature, formatting references, translating text, and explaining concepts.
4. [Coding]({{ "/tool/coding/" | relative_url }}): writing, explaining, translating, and debugging code.
5. [Data analysis]({{ "/tool/analysis/" | relative_url }}): creating figures, extracting data from text, reformatting data, classifying and scoring text, and simulating human subjects.
6. [Mathematical derivations]({{ "/tool/math/" | relative_url }}): setting up models, deriving equations, and explaining models.

Each of these uses is a variable cost: one prompt per task. [Infrastructure]({{ "/infrastructure/" | relative_url }}) covers the fixed costs.
